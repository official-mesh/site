A small ESP32-S3 application that draws a boot menu on the OLED and rewrites
`esp_ota_set_boot_partition()` based on which firmware you pick. Useful for
A/B-ing protocols on the same hardware without burning USB-port time on
re-flashes — and for keeping a known-good fallback one button away. The
flasher expects pre-built firmware bins; see the project README for the build
sequence.
