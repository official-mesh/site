An Android app that connects out to a running Meshbot. The operator can fire
hooks, send slash commands or freeform text into the host's console, watch the
console output stream live, and optionally bridge a USB or BLE radio back to
the host. The wire protocol is a thin frame on top of Meshtastic's `ToRadio` /
`FromRadio` protobuf with separate control and data planes; reconnects with
exponential backoff; degrades cleanly when the host is offline.
